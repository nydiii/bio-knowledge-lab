可各写一两句话；暂时答不出的地方直接写“不明白”。不需要重复写一份完整实验报告。

- 实践开始前，我以为这项任务要做什么；现在我认为它要做什么：
- 选一条自己看过的记录（填写文献 ID 或输出文件）：原文里的实体名称是什么？抽取得到什么？对齐又增加了什么？
- 本次哪些内容来自模型，哪些工作由程序完成？我是否重新调用了模型？
- 我能解释的一步：输入是什么、输出是什么、为什么需要这一步？
- 最难理解的词或步骤，以及具体困惑：例如“对齐后多了标准 ID，但我还不明白它和原文名称的区别”。
- 若使用 AI 或他人帮助：我问了什么、得到什么解释、用哪段原文或哪个输出核对过？还有哪里没懂？
