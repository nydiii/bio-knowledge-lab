# 教师说明、评分与参考答案

本实训让学生处理同一批真实文献：从摘要中抽取实体和关系，关联跨文献对象，保留独立证据，再核查、修订及加入新文献。学生可以使用免费真实回放完成全部本地知识库操作，也可自行配置 API 重新抽取。

## 参考答案的层次

1. **原作者人工标注**：`data/reference/gold.jsonl` 对应固定版本的 BioRED，包含原始标注身份和转换信息。它用于评分，不输入待测抽取或对齐方法。
2. **课程确定性参考**：来源和位置核验、重复导入不增加记录、教学故障恢复、更新历史与查询变化。这些由程序和保留的原始副本验证。
3. **候选科学解释**：模型生成的最小证据句、额外上下文、争议判断。没有独立金标时保留待审状态，不把模型一致性当作专家确认。

无需教师重新标注全部原数据。拟修改原金标，或把第三类候选正式纳入评分参考时，再安排集中审阅。

## 建议作业与评分

| 板块 | 学生提交物 | 建议分值 | 验收重点 |
|---|---|---:|---|
| 原文与来源 | 资料清单、文件哈希、初始／增量划分说明 | 10 | 文献真实可定位；不把课程分组混作原作者训练／测试分组 |
| 科学信息抽取 | 抽取 JSONL、金标评价报告、至少三类真实错误分析 | 25 | 实体边界／类别与关系评价分开；漏抽、错抽、格式错误不隐藏 |
| 对齐与融合 | 对齐结果、跨文献查询、歧义／未解析案例说明 | 25 | 同物异名能关联；同名异物种不误合并；文献证据没有相互覆盖 |
| 校验与修订 | 问题列表、修订依据、历史、修订前后查询 | 25 | 能区分结构错误与科学疑点；教学故障与模型错误分开统计 |
| 增量与复现报告 | 新文献导入、重复导入检查、环境及方法边界说明 | 15 | 增量可追踪；回放与真实调用如实标记；结果可由他人重现 |

可调整分值，但不要把“模型 F1 必须达到论文数字”作为教学适配的通过条件。评分应奖励可追溯的错误分析和正确更新，而不是鼓励修改金标让指标变高。

## 必答问题

1. 为什么两个不同名称可以连接同一标准 ID，而两个同名实体可能不能合并？给出本次资料中的实际记录。
2. 同一对象出现在多篇论文中后，数据库新增了哪些证据？哪个查询能证明这些证据仍独立保存？
3. 举例说明负相关、未标注关系、背景知识、证据不足的区别。
4. 一个字符跨度完全匹配原文，是否足以证明关系正确？说明还缺什么判断。
5. 修订了一条关系后，当前查询和历史分别怎样变化？为什么不能直接覆盖原始 API 响应？
6. 加入增量文献后，再导入同一文件，结果是否重复增加？用实际输出解释。
7. 哪些字段有作者人工金标？哪些只是课程或模型新增字段？

这些题目的具体文献编号和数值由学生的运行结果决定。教师应保留本次发布对应的 `VERIFICATION.md` 和数据 manifest，避免拿不同版本的计数互相判错。

## 人工审阅方法

使用 [MANUAL_REVIEW.md](MANUAL_REVIEW.md) 和 [REVIEW_RETURN.md](REVIEW_RETURN.md)。先检查拟进入评分参考的数据，再审阅真实模型错误、实体歧义和额外上下文。无法确定的项目保留“待审”，可作为讨论题；不要求强行选一个生物学结论。

## 避免评价泄漏

- 抽取提示不含当前文献的 gold 实体、关系或标准 ID。
- 外部词典由独立来源建立，不能只从选中文献的金标反推候选。
- 可用训练样例解释标签；不得把待评样例与答案同时输入模型。
- 学生修订后的知识库与原始预测分别评价；不能用人工修正后的结果冒充首次抽取分数。
- 增量资料的 gold 可封存在教师目录，但“新增文献”不代表发表时间更新。

## API 与学生费用

教师制作发布回放时，项目总 API 预算为 5 元；真实调用记录与费用应随发布提供。学生使用免费回放不需要密钥。学生自行调用时使用自己的账号和单独的预算账本，不能共享教师密钥。费用控制不是科学质量证明；预算耗尽而未完成的调用应记录为未完成。
