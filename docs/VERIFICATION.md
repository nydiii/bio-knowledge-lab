# 实际验证记录

记录日期：2026-11-12。平台：macOS 26.6 / Apple Silicon，Python 3.12.15。所有神经模型实验指定 CPU，未用独立显卡。跨系统 CI 的最终状态见 GitHub Actions；未实际取得的结果不在此宣称通过。

## 已运行的真实流程

1. 官方 BioRED、NCBI Gene/Taxonomy、NLM MeSH 下载和哈希固定；600 篇原始实体坐标全部检查。
2. 确定性选择 50 篇（40+10），共 2525 个参考实体、1197 条参考关系；按共享基因/疾病构成单个文献关联图。
3. 对全部 50 篇真实调用 DeepSeek：实体识别、关系抽取、来源证据核查、上下文实体链接。当前共 216 次真实调用，另含早期 50 次链接及 16 次改正后重录。无合成响应冒充 API。
4. 全部文献的词典、CPU SapBERT、上下文链接三条路线运行并独立评价。
5. 完整免费 `demo`：40 篇导入、原文核查、教学错误、参考恢复、10 篇增量、幂等导入、查询及历史。
6. 离线全流程测试通过；测试中禁止 urllib 网络访问，保证回放没有暗中调用模型。

最终本地测试为 **38 项通过**。另建只安装本项目和 pip 的干净 Python 3.12 环境，没有 torch/transformers，完整 `demo`、`verify` 和学生回传脚本均通过；[流程验收输出](../reports/workflow_verification.json)保存了18项验收结果。按分步手册独立执行23条命令通过，包含增量文献核查；另测试过期修订返回错误且不改变查询。

## 证据核查的含义

50篇、690个候选的模型来源核查输出：636 `supported_text`、42 `insufficient_text`、7 `contradicted_text`、5 `invalid_judgment`。

这些标签表示模型对“原文是否支持候选抽取”的判断，**不是独立正确率，也不验证标准ID是否正确**。引文必须是源文档的精确子串；不符合者降为无效判决。原 BioRED 没有逐句证据及完整上下文 gold，因此没有为这些字段制造 F1。

源文档全文摘要参与核查。跨文献 BM25 的句切分目前以终止标点/文本末尾为边界，可能遗漏无句末标点的标题或换行段落；返回内容只是检索候选，不声称检索穷尽所有相关证据。

## 预算与回放

[api_usage.json](../reports/api_usage.json) 保留脱敏逐次用量及响应编号。216 次调用累计按输入2元/百万、输出8元/百万的官方高峰价并忽略缓存优惠估算：**3.641656 元**。这不是账户账单确认值，实际计费可因空闲时段和缓存优惠更低。所有开发调用共用一个5元账本。

第一个上下文链接实验保存在原 `.link.json` 中，后来纠正了“整篇单一物种不能决定所有基因物种”的规则。16篇提示变化的结果另存带提示哈希的文件；不覆盖旧响应，费用全部累计。当前回放自动匹配正确提示版本。

免费回放 API 调用数为0、模型费用为0。数据与响应哈希由 `verify` 验证；API密钥未放入仓库。
