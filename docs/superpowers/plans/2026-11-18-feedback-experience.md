# 审阅反馈驱动的改进体验 Implementation Plan

**Goal:** 学生免费完成旧版运行、发现真实问题、理解局部改进、运行新版和比较结果；不要求提交表格或报告。

**Architecture:** 保留发布主线、真实回放和原 BioRED 金标。新增独立 `feedback-lab` 分步入口，以同一份旧预测运行有来源的本地规则改进；参考答案仅供诊断和评价读取。原意见按字段归类，不把学生意见或模型裁判直接升级为科学金标。

**Tech Stack:** Python 标准库、现有 JSONL/评价器、Markdown 教程、pytest。

**Spec:** 本会话已确认的六步体验；此次反馈覆盖 22/24 条，两个未审项目继续待审。

## Constraints

- 不要求学生填写或提交审阅表；程序自动生成可阅读的对照说明。
- 不读取金标生成预测，不硬编码文献或目标 ID；原始回放、金标与旧版结果不可覆盖。
- 不新增付费 API 调用；新版是固定真实模型结果上的本地规则处理，不能冒充新模型推理。
- 实体识别不变；链接优化与局部关系规则分别留痕，候选仍非专家确认。
- 以涉及本轮审阅的文献为开发案例，其余文献为本轮未参与调整的验证集；不称独立测试集。
- 程序和教程不公开学生姓名、个人路径、原始反馈附件或环境明细。
