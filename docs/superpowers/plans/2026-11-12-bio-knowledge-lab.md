# Bio Knowledge Lab Implementation Plan

**Goal:** 完成已授权的多文献生物知识建模教学仓库、两条运行路径和诚实的验收与人工回传说明。

**Architecture:** 原文、外部 KB、gold 与真实模型回放分开保存；抽取输出连接 CPU 对齐、SQLite 文献证据库、核查与带历史的更新。串行预算账本控制所有付费请求。

**Tech Stack:** Python 3.12、SQLite、JSONL、urllib；可选 CPU SapBERT；pytest 与 GitHub Actions。

**Spec:** docs/SPEC.md

## Global Constraints
- 普通电脑，无独立显卡；付费调用累计 ≤5 CNY，凭据不输出、不提交。
- 完整流程和跨文献实践；不把模型候选冒充 gold，不泄漏评估标注。
- 复现与适配分别说明；所有未完成科学审阅明确 pending。

## Review Focus
- BioRED 原文坐标在标题/摘要转换时偏移：精确子串校验。
- 同名异物种与一对多 ID：保留歧义，不能任意合并。
- 同一实体对的多篇证据和不同标签：分别保存。
- API 超时/截断/重试：已预留款不能遗失、不得自动重新收费。
- 修订、重复导入和增量：历史不覆盖、重复不膨胀、查询实际改变。
