# 生物科学知识建模实训

用50篇真实生物医学摘要，体验**整理文献 → 查询关联 → 核查和修订 → 加入新文献 → 发现问题并比较改进效果**。

## 学生从这里开始

**只看这一份：[完整学生操作教程](docs/MANUAL.md)。**

- 第一次做：从第1步开始，按顺序操作。
- 已经完成原教程：更新项目并按第1步确认环境可用后，从第8步继续。
- 每一步都说明做什么、为什么做、打开哪个结果看。
- 普通电脑即可，推荐 Python 3.12；免费读取保存的真实 AI 回答，不需要密钥或独立显卡。
- 不用交表或报告。下载项目请选择 **Code → Download ZIP**，解压到新文件夹。

原来的基础教程和改进教程已合在同一页。旧改进教程链接只保留跳转提示。一键演示、额外模型对照和付费调用不属于本次必做内容。

## 方法与结果

课程借鉴公开论文的部分方法，构成完整的教学流程；它不是相关论文全部训练实验和指标的严格复现。原作者入口和具体适配见[方法说明](docs/METHODS.md)。

在本课程固定50篇上，改进体验的链接 F1 从61.92%到62.17%，端到端关系 F1 从17.28%到17.40%。两版使用同一份原始抽取与人工参考；本轮改变5处编号和3处关系标签，仍有未解决的问题。分数提高与程序检查通过，都不等于整个资料库已经通过科学审定。

免费回放读取的是此前实际调用的回答，不会让模型重新回答。维护者仍可使用代码中的真实 API 路径；它需要单独配置密钥和预算，不属于学生本次操作范围。
